Investigate failed sign-ins

Which account shows a repeated failure pattern?

09:01  editor  success
09:02  admin   failed
09:02  admin   failed
09:03  reader  success
09:03  admin   failed
Reveal finding

The admin account had three failures in about a minute. Review the surrounding sign-in events and correlate the failures with other activity before concluding what caused them.

Review browser security headers

Which header tells the browser to block framing by other sites?

Content-Type: text/html
X-Content-Type-Options: nosniff
X-Frame-Options: DENY
Reveal finding

X-Frame-Options: DENY blocks the page from being embedded in a frame, including by its own site. This helps protect against clickjacking.
